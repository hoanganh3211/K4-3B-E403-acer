## Đọc nhanh theo tình huống

- **"Nhóm mình chưa chắc pain có thật không"** → Mom Test (3 quy tắc, Deflect/Anchor/Dig), rồi PAIR chương 1.1.
- **"AI nên tự làm hay chỉ gợi ý?"** → PAIR 1.2 (automation vs augmentation) + guide §2.3.
- **"Chọn nguyên tắc nào cho spec §4b?"** → `hax-guidelines.md` (G10 bắt buộc) + PAIR chương 3–5.
- **"Nghĩ không ra kịch bản lỗi"** → PAIR chương 6 (bốn nguồn lỗi) + HAX Playbook.
- **"Định nghĩa 'tốt' để đo thế nào?"** → PAIR 2.3 (bảy chiều chất lượng) + guide §2.6.
- **"Đi test với người thật"** → guide §4.2 + PAIR 5.1 (tín hiệu hai nghĩa: regenerate, edit, dwell, follow-up).

Mọi tóm lược trong thư mục này là bản viết lại của BTC để dùng trong khoá; trích dẫn/đọc sâu thì dùng bản gốc và ghi nguồn.
